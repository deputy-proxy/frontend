# G

- Premise: A Romanian typographic broadside: the page uses compressed hierarchy and large Romanian diacritics as part of its visual identity.
- Fonts: Arial Narrow/Arial for display; Georgia for supporting statement.
- Flat canvas: #111111
- Active text colors: #F1EBDD, #C7A24A
- Signature: Dark broadside using Romanian language and diacritics as visual material.
- Round 2 invariant: preserve the typographic reading path, hierarchy, whitespace rhythm, and palette roles before introducing production UI.
- Assumptions: no external font dependency; system-available stacks only.
- Risks: display font availability varies by operating system; verify Romanian diacritics in production.
