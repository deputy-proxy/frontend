# React Bits Pro Agent Kit

Source: https://pro.reactbits.dev/docs/agent-kit

The Agent Kit separates **what the page says** from **how it looks**:

- Design Skill = visual system and interaction language.
- Vertical Prompt = business/content requirements and information architecture.
- Recipe = ordered block assembly and harmonization.
- Registry Skill = installation/search mechanics.

This is the most important conceptual model to import into the local Author workflow.

## Setup

### React Bits Pro Skill

## Agent Kit operating principle

A good composition is not:

`random blocks + random animation + random visual effects`

It is:

`business objective -> content model -> vertical prompt logic -> design skill -> block selection -> harmonization -> responsive/accessibility validation`

The React Bits Agent Kit explicitly demonstrates that the same content structure can be rendered through different design skills. The local Author should adopt that separation.

## Harmonization pass

After selecting blocks, unify:

- typography and hierarchy;
- color and accent logic;
- container width;
- spacing rhythm;
- border/radius language;
- surface treatment;
- image/media treatment;
- motion timing and easing;
- scroll behavior;
- responsive transformations.

Never leave a page looking like a collage of independently selected blocks.
