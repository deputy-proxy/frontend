## Block composition rules

- Blocks are complete **sections**, not tiny UI primitives.
- Prefer one dominant block per information job.
- A page should be harmonized after block selection: type, spacing, palette, surfaces, radius, motion, and container behavior must feel like one system.
- Do not blindly use the same numbered variant across unrelated pages.
- Treat variant numbers as identifiers, not quality rankings.
- For a standalone HTML page, translate the structure and motion concept rather than importing React source unnecessarily.
